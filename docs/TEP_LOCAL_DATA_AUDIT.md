# 로컬 TEP 참조 데이터 확인

2026-10-09. 추가된 경로: `archive/TEP_data/`.

## 분류

동봉 `readme.txt`는 Fortran 기반 TEP 개루프/폐루프 시뮬레이션 코드와 정상·고장 학습/시험 데이터를 설명한다. 따라서 현재 분류는 **시뮬레이션 참조 데이터**이며 현장 실측·실제 설비 검증 자료로 등록하지 않는다. MIT Braatz 그룹의 [소프트웨어 안내](https://web.mit.edu/braatzgroup/links.html)도 TEP 자료를 simulation data로 소개한다. 사용자가 업로드한 파일의 실제 다운로드 URL·원본 버전은 아직 확인 중이며 공식 배포 파일과 바이트 일치를 확인한 상태는 아니다.

동봉 README에는 University of Illinois 1998–2002 저작권, 사용·복제·수정·배포 허가와 고지 유지·보증 부인·명칭 사용 조건이 있다. 코드/문서 고지는 원본에 남겨둔다. 데이터 파일에 대한 정확한 라이선스 적용 범위와 원배포 출처는 추가 확인하며 이번 확인에서 원본 자료를 GitHub에 재배포하지 않았다.

## 파일 검사 결과

44개 `.dat`, 정규화 후 총 **31,700개 관측**, 관측마다 52개 값. 모든 파일을 읽었으며 NaN·무한대는 0개다. 구조 검사 통과는 물리 정확도나 출처 검증 완료를 뜻하지 않는다.

| 파일 | 실제 저장 형태 | 읽을 때 처리 |
|---|---|---|
| `d00.dat` | 52행 × 500열 | 전치하여 500행 × 52열로 읽기 |
| `d01.dat`..`d21.dat` | 각각 480행 × 52열 | 행마다 관측 |
| `d00_te.dat`..`d21_te.dat` | 각각 960행 × 52열 | 행마다 관측 |

README의 학습 파일 480행 설명은 실제 `d00.dat`의 500개 표본 및 전치 형태와 다르다. 파일을 일괄 480행으로 자르거나 잘못된 방향으로 읽지 않는다. 파일별 원본 SHA-256·관측 수·유한값 검사·선택 변수 통계는 로컬 `data/tep-local-data-audit.json`에 보존했다. 원본 파일은 변경하지 않았다.

동봉 변수 순서는 `XMEAS(1..41), XMV(1..11)`이다. XMV(12)와 전체 50 내부 상태는 이 관측 배열에 없다. 냉각수 입력 XMV10/11은 1부터 세는 **51/52번째 열**이며 Python 인덱스는 50/51이다. 단위는 동봉 모델과 현재 변수 사전을 대조해 사용해야 하며 실제 펌프 RPM으로 해석하지 않는다.

전치한 정상 학습 `d00.dat`의 확인 예:

| 변수 | 최소 | 최대 | 평균 |
|---|---:|---:|---:|
| XMEAS7 반응기 압력 (kPa gauge) | 2690.5 | 2715.8 | 2705.3974 |
| XMEAS9 반응기 온도 (°C) | 120.35 | 120.45 | 120.39944 |
| XMV10 반응기 냉각수 설정 (percent_full_scale) | 39.51 | 42.641 | 41.09475 |
| XMV11 응축기 냉각수 설정 (percent_full_scale) | 14.009 | 23.144 | 18.215882 |

이 최소·최대는 해당 시뮬레이션 기록의 통계이며 정상 운전 또는 안전 허용 한계로 등록하지 않는다.

## 현재 실행 모델과 비교할 때 필요한 확인

- `temain_mod.f.txt`는 plant-wide 폐루프 제어를 포함한다. 원본 코드 설명/출력 루프는 180초 기록 간격이며 적분은 1초이다. 각 `.dat`에 timestamp가 없어 파일별 실제 시작 시점·간격·전처리를 별도 확인해야 한다. 확인되지 않은 시각을 실제 계측 시각으로 생성하지 않는다.
- 동봉 코드에는 3/360/900초 주기의 여러 제어 루프와 8시간 이후 외란 적용 설정이 있다. 현재 코드 한 벌의 외란 설정을 모든 `d01..21`의 실제 생성 설정으로 간주하지 않는다.
- `teprob.f.txt`의 현재 seed는 `4651207995`이고 파일별 seed 후보가 주석으로 남아 있다. 주석의 대응이 실제 파일 생성 기록과 일치하는지는 아직 검증하지 않았다.
- 현재 Iron-Man NIST 경로는 원본 기본 상태·시드 1431655765·제어기 없음·0.1초 적분·기본 10초 관측·최대 1800초 시험이다. 폐루프 기록과 초기 상태·시드·제어·시간축이 일치하지 않는다.
- 관측 52개를 내부 50 상태의 체크포인트로 사용하지 않는다. 대응 조건 없이 현재 모델과 행 순서만 맞춘 RMSE를 정확도나 현장 오차로 표시하지 않는다.

사용 가능한 다음 작업은 공개 TEP 정상/고장 통계와 변수 로더, 출처 확인 후 동일 제어기·초기 상태·시드·입력 이력의 참조 재현 비교다. 실제 설비 오차·현장 적용성 검증은 별도 실측 자료가 확인될 때 진행한다. **현재 실측 검증은 미완료, TEP 승인 정책은 hold 상태를 유지한다.**

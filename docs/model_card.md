# 냉각 탱크 데모 모델 카드

버전: `cooling-demo-v1`. 대상은 합성 초기 상태를 가진 단일 냉각 탱크와 펌프다. 실제 PLC나 설비와 연결되지 않는다.

## 계산

1초 간격으로 300초 등 명령의 `duration_s`만큼 계산한다. 온도 변화율(°C/s)은 `0.15 × load_ratio − 0.002 × effective_pump_speed_pct × cooling_efficiency`다. 유효 펌프 속도는 매 초 `(target_pct − effective_speed) / 20`만큼 목표에 가까워진다. 정상 효율은 1.0, 효율 저하 시험은 0.65다. 계수와 80°C 제한은 모두 데모 가정이며 실측 보정값이나 산업 안전 기준이 아니다.

기존 속도 유지와 요청 속도 적용은 동일한 온도·부하·펌프 속도·효율에서 시작한다. 내부 계산은 시간별 온도와 최초 한계 초과 시각을 추적한다. 현재 팀 공통 API v1.0에는 시나리오별 최고 온도와 한계 초과 여부만 반환한다. 80°C **초과**만 위반으로 처리한다.

## 입력 범위와 한계

초기 온도 0~120°C, 부하 비율 0~1.5, 펌프 속도 0~100%, 유효한 센서 품질, 양의 관측 시각만 지원한다. 범위를 벗어나거나 센서 품질이 불량하면 `out_of_domain`, 빈 `scenarios`, 사유가 포함된 `limitation`을 반환한다. 관측 시각의 노후 여부는 호출 시각이 필요한 1번 관문 서버에서 검사한다.

모델은 외기 온도, 열용량 변화, 유량 곡선, 열교환기의 비선형성, 센서 오차, 통신 지연, 전력 소비를 재현하지 않는다. 합성 데이터로 흐름을 검증할 뿐 실제 설비의 정확도나 안전성을 입증하지 않는다. `mock=false`는 고정 응답 대신 계산을 수행한다는 뜻이며 실측 검증을 의미하지 않는다. 팀의 v1.0 관문 정책은 이 결과가 한계를 넘으면 차단하고, 넘지 않아도 승인 정책 미설정으로 보류한다.

시뮬레이션은 상태를 읽기만 한다. 가상 설비의 명령값 변경은 승인 후 관문 서버가 별도 `DemoAdapter`를 호출할 때만 일어난다.

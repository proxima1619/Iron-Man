스크립트와 Git LFS 경로를 추가했다. 실제 제공처 메타데이터에서 이용 조건과
체크섬을 확인한 파일만 다운로드 완료로 처리한다. 이 실행 환경의 네트워크가

아직 없다. 모델 또는 홈페이지 데이터를 TEP로 바꾸지는 않았다.
팀원이 일반 터미널에서 다운로드와 LFS 업로드를 완료해야 원본이 공유된다.

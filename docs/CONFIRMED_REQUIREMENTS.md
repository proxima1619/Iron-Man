# 확정한 요구사항과 남은 합의

2026-10-09 사용자 대화 기준. 계획과 현재 구현을 구분합니다.

## 확정

- Track 1 설비 변경 안전 관문. 첫 예시는 냉각 펌프 속도 변경.
- 실제 설비 실측 데이터는 현재 없고 팀에서 찾는 중이다. 실측 확보를 기다리지 않고 TEP 외부 연동·재현 가능한 기준/변경 실행을 먼저 진행한다. 생성 결과는 시뮬레이션 데이터로 표시한다.
- 기존 합성 탱크의 승인 명령은 가상 설비에만 적용한다. TEP의 위험·근거·승인 정책은 미설정이므로 계산 성공도 보류하며 실제 설비에 적용하지 않는다.
- 1번은 진행·권한·최종 실행 판정, 2번은 상태·계산·설비 모델, 3번은 출처·적용 조건·반례, 4번은 담당자 이해와 판단 화면.
- negligible을 넘는 편차는 지정 승인자에게 예외 검토를 요청한다. 하드 제한 위반·무효 결과는 보류 또는 차단한다.
- 이메일은 알림과 요청자 연락을 위한 수단이다. 이메일 수신이나 클릭을 승인으로 사용하지 않는다.
- 요청·보고서·판단·실행·알림 이력을 DB에 연결하고 GitHub에 개발 내용을 올린다.

## 구현된 것

기존 SQLite·v3 가상 어댑터·가상 설비 전용 승인 정책·비동기 평가에 4번 검토 화면, 최고 온도 비교, 출처·조건·모델 한계, 재시험 요청, 역할 조회, 선택 연락처와 알림 기록을 연결했다. 기존 정책의 가상 승인 대기는 유지하며, 팀의 편차 기준을 추가 설정하면 초과 결과를 지정 승인자의 예외 검토로 표시한다. 상세 API와 운영 제약은 [MODULE4.md](MODULE4.md)에 있다.

## TEP 계획과 현재 모델의 차이

사용자는 TEP 외부 시뮬레이터에 제어 입력을 주어 실제 계산 결과를 가져오는 방향을 확정했다. 현재 **NIST TEP 코어 고정 커밋 기반 외부 프로세스 연동**을 구현하고 기준/변경 시계열·반복 실행·실패 보류를 확인했다. 기본 요청 화면은 TEP이고 기존 `cooling-demo-v3` 합성 탱크는 별도 경로로 남긴다. 상세한 선택·설정·라이선스·실행·검증 결과는 [TEP_INTEGRATION.md](TEP_INTEGRATION.md)에 있다.

참고할 원저는 Downs & Vogel, *A plant-wide industrial process control problem* (1993), [DOI](https://doi.org/10.1016/0098-1354(93)80018-I), [저자 논문 사본](https://users.abo.fi/khaggblo/RS/Downs.pdf)이다. TEP는 산업 공정을 바탕으로 구성·조건을 수정한 연구용 공정 모델이다. 냉각수 제어 입력을 펌프 RPM과 동일하게 취급하려면 별도의 매핑을 설명해야 한다. 따라서 현재 데모의 80°C 제한과 60/80% 명령을 TEP에 그대로 적용하면 안 된다.

공개 정상 시뮬레이션 이력의 후보는 Rieth et al. (2017), *Additional Tennessee Eastman Process Simulation Data for Anomaly Detection Evaluation*, [Harvard Dataverse DOI](https://doi.org/10.7910/DVN/6C3JR1)이다. 이는 현장 실측 기록이 아닌 시뮬레이션 데이터다. 데이터 파일·라이선스·체크섬·정상 구간·변수 사전은 2번 담당이 실제 다운로드 시 확인하고 기록해야 한다. 이번 변경에는 원본 데이터를 재배포하지 않았다.

정상 운전 이력의 센서 벡터만으로 내부 물질 재고·조성 등의 완전한 시뮬레이터 상태를 복원한다고 가정하지 않는다. 사용하는 TEP 구현의 초기 상태와 제어기, 운전 모드, 랜덤 시드, 관측 주기 및 시험 시간 구간을 함께 기록해야 한다.

검증은 두 단계다. **1단계**는 현재 구현의 반복 재현성·입출력/단위·기준/변경 비교·실패 보류이며 실제 외부 실행으로 확인했다. **2단계 실측 오차 평가와 실제 설비 적용성 검증은 미완료**다. 실측 자료의 태그·단위·시간 간격·운전 조건과 독립 검증 절차는 TEP 안내에 정리했다. 데이터 확보만으로 자동 승인이나 현장 검증 완료로 바꾸지 않는다.

## 4번 연결을 위해 받을 값

| 담당 | 추가로 필요한 계약 |
|---|---|
| 1번 | 개인 승인자 인증·세션, 최종 정책, 알림 설정·운영 주소 |
| 2번 | 예측/참조의 같은 시간축·단위, 잔차 통계, 이상 구간, 검증 범위, 모델 버전 |
| 3번 | 실제 출처 locator/URL/버전, 적용·미확인 조건, 부족 상태, 연결 시험 ID |

기존 탱크의 `assessment`는 최고 온도 차이이고, TEP의 `tep_simulation.comparison`은 같은 시간축의 변수별 기준/변경 차이다. 둘 다 실측 오차가 아니다. TEP 시계열·변수·단위는 추가 계약으로 연결했으며 없는 실측 잔차·검증 정확도를 생성하지 않는다.

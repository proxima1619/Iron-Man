# 4번: 논문 검토 연결과 기록 표시

- DB 요청/보고서 조회와 API 키를 사용하는 새 LLM 검토를 화면에서 구분했다.
- 인증된 `/evidence/catalog`를 추가하고 공통 OpenAPI·프런트 타입을 갱신했다.
- 로컬 출처 목록, 키·모델 설정 여부, 문서 검증 실패를 표시한다. 키 값은 반환하지 않는다.
- 실제 검토 카드를 지지·반례·한계 순서로 표시하고, 원문 인용·적용 조건·부족 조건을 유지한다.
- LLM에 양쪽 관점 검토와 근거 부재 명시를 요구했다. 인용문은 입력 문서의 연속 부분 문자열인지 기존 검증을 거친다.
- 논문 검토에서 지지 또는 반례 카드가 없는 경우 부족 조건을 추가한다. 반대 논문이나 안전 승인을 생성하지 않는다.
- 현재 사전 수집 논문은 `data/sources/paper-sources.json`의 3편이다. API 키를 설정하고 새 요청을 평가해야 실제 분석이 저장된다.
- 기존 보고서, 실제 설비 실행 권한, 외부 출처 승인 정책을 유지했다.
- Python 문법 컴파일과 프런트 TypeScript 검사를 완료했다. 실제 유료 LLM 호출과 브라우저 화면 검증은 수행하지 않았다.

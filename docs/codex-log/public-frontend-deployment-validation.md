## 범위와 운영

Kakao 실제 앱·다른 사람의 단말·네트워크는 직접 시험하지 않았다. User-Agent 응답 확인을 실제 앱 검증으로 표현하지 않는다. 새 주소를 일반 Chrome에서 검증했으며, 다른 단말에서 루트 URL을 눌러 확인하는 최종 시연은 별도로 진행한다.

4번은 frontend 변경을 main에 push하면 된다. 반영은 CI 시간 + 빌드 + 최대 1분의 확인 시간이며, 로컬 저장이나 다른 브랜치는 배포하지 않는다. 백엔드·정책·환경변수 변경은 1번이 별도로 배포한다. 새 API가 필요한 화면은 백엔드를 먼저 반영해야 한다. 운영 명령은 [배포 문서](../DEPLOYMENT.md)를 따른다.

TEP 성공 결과도 전용 정책 미설정으로 보류한다. 실제 설비는 연결하지 않았다. LLM API 키는 아직 연결하지 않아 fixture 근거를 사용한다. 참조 원본 데이터가 없는 상태에서 핵심 TEP 실행은 가능하다. 실측 오차·실제 설비 적용성 검증은 완료로 표시하지 않는다.

무료 IP 기반 DNS 주소이므로 현재 EC2 IPv4가 바뀌면 주소·Caddy·timer의 공개 URL을 함께 수정해야 한다. SSH 개인 키·역할 토큰은 공개 저장소에 포함하지 않는다.

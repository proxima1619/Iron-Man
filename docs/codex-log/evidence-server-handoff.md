# 3번 서버 인계 기준 반영

사용자가 전달한 1·2번 합의를 반영했다. 서버 정책과 시뮬레이터의 공통 계약·효율값은 변경하지 않았다.

- degraded_cooling은 efficiency 1.0 → 0.65인 포괄적 데모 반례이며 특정 고장이나 실측 안전성 검증이 아님을 검토 입력과 프롬프트에 명시했다. 펌프 응답·부하·냉각수 온도 유지 조건도 전달한다.
- 미지원 시험명은 검증하지 못함과 2번 계약 합의 필요를 기록하고 시험 후보에서 제외한다. 추가 효율 필드·잘못된 출력은 실패로 처리한다.
- 적용 조건 비교가 비어 있으면 insufficient로 보류한다. 검토 실패는 설정/원문 수집/LLM/출력 검증 단계를 표시하고 제공자 응답이나 비밀을 포함하지 않는다.
- 서버의 신뢰 원문 목록으로 출처·인용·후보 연결을 재검증하는 읽기 전용 validation.py를 추가했다. 출처 허용·적용 조건 의미 판단·승인은 서버 책임이다.
- contracts/examples/evidence-handoff에 정상·근거 부족·실패·미지원 시험 JSON을 저장했다. 실제 LLM 결과가 아닌 자동 검증 예시임을 limitation과 manifest에 명시했다. 근거 부족 예시는 실제 수집 논문의 인용을 사용한다.
- docs/evidence_server_handoff.md에 출력 필드, 배포 환경변수, 연결 책임, 재현 명령을 정리했다. API 키는 저장하지 않았다.

검증: 전체 pytest 235 passed, 근거 관련 전용 묶음 82 passed, git diff --check 통과. 기존 TestClient deprecation 경고 1건. 실제 LLM 추론과 배포 서버 운영은 미검증이며 1번의 키·모델 설정 및 외부 출처 정책 연결 이후 확인해야 한다.

공유 직전 fetch에서 main의 0210197까지 확인하여 충돌 없이 통합했다. 담당자 검토 UI·연락/알림·장기 물리 평가가 포함된 최신 main으로 전체 pytest **258 passed**, TypeScript·Vite 빌드 통과를 확인했다. 3번 변경에서 서버 정책이나 시뮬레이터를 수정하지 않았고 기존 팀원의 보호 규칙을 유지했다.

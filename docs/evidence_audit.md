# 3번 구현 재검증 — 2026-10-09

검증 시작 커밋: 7d3db02. 기존 전체 82개 테스트는 통과했지만 추가 경계 시험에서 7개 실패를 재현했다.

## 발견과 수정

| 발견 | 수정 |
|---|---|
| 공백 주장·공백 인용이 유효한 카드로 처리됨 | LLM 텍스트·조건의 공백 값 거부. 원문 문자열은 바꾸지 않고 대조 |
| 카드에는 미확인 조건이 있으나 최상위 목록이 비면 completed 반환 | 카드·전체 누락 조건 병합, insufficient와 limitation에 표시 |
| https://만 있는 URL·알 수 없는 출처 유형 허용 | HTTPS 호스트 및 출처 유형 검증 |
| 설치형 런타임의 원문 파일 경로를 지정할 수 없음 | IRON_MAN_EVIDENCE_SOURCE_PATH 지원 |
| Docker 빌드 문맥에서 문서가 제외되고 이미지에 복사되지 않음 | data/sources 포함, 이미지 /app/data/sources에 복사, 경로 지정 |
| Compose가 LLM 환경변수를 전달하지 않음 | 검토 모드·키·모델·timeout 전달. 기본 fixture 유지 |

## 검증 내용

- 인용·출처 위조, 금지 시험·승인 필드, 불일치, 공백 텍스트, 부족 조건.
- 중복·누락·잘못된 URL·유형·과대 문서와 빈 문서 묶음.
- 모델 응답 미완료·거부·빈 응답·잘못된 JSON, HTTP 429, 과대 응답, timeout 설정 오류.
- 모의 LLM 출력으로 실제 FastAPI 응답 모델 검사, SQLite 저장, 서버 재시작 후 같은 보고서 복원.
- 위험 반례가 물리 시뮬레이터 추가 시험으로 전달되고 실행되지 않는지 확인.
- 문서의 악성 지시와 금지 출력 필드 검사. 실제 모델 공격 저항 평가로 주장하지 않음.
